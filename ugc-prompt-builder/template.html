Cara pakai

  1. Klik Salin prompt.
  2. Pilih AI yang mau dipakai (ChatGPT, Gemini, atau Claude), lalu klik Buka. Pilih salah satu saja.
  3. Di chat baru, lampirkan foto produk dan foto model (kalau sudah punya, hasilnya lebih bagus), tempel prompt, lalu kirim.
  4. Minta revisi langsung di chat itu kalau perlu, misalnya "ganti dialog shot 2 jadi lebih santai".

Hasil yang akan kamu dapat dari AI

1. Prompt gambar kreator
Tempel ke ChatGPT Images atau Nano Banana bersama foto model.png. Simpan hasilnya sebagai creator.png.
2. Shot list
Naskah iklan per adegan: lokasi, aksi kreator, produk tampil atau tidak, dan dialognya. Ini untuk kamu baca dan cek dulu, bukan untuk ditempel ke Flow. Edit dialog di tahap ini gratis, sedangkan generate ulang video makan kredit.
3. Prompt Flow per shot
Satu prompt untuk satu klip video. Tempel satu per satu di Flow, dengan creator.png dan foto produk sebagai ingredient.
4. Briefing Agent mode
Satu teks untuk membuat semua shot sekaligus. Hanya jalan kalau Agent mode di Flow sudah aktif.
5. Skrip voiceover
Dialog lengkap dengan timing, untuk dibuat suaranya di ElevenLabs lalu digabung di CapCut.
