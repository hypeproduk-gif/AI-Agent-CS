UGC Prompt Builder

Isi data produk, pilih angle dan kreator, lalu salin satu prompt lengkap ke ChatGPT, Gemini, atau Claude. AI akan menulis paket produksi iklan UGC untuk Google Flow.

  • 1 Isi brief
  • 2 Salin prompt
  • 3 Tempel di AI + lampirkan foto produk
  • 4 Pakai hasilnya di Flow

Produk

Boleh lebih dari satu foto dari sisi berbeda (depan, belakang, samping, detail). Beri nama file sesuai sisinya. AI akan memilih foto yang paling sesuai untuk tiap shot. Lampirkan semua foto ini saat menempel prompt.
Penting kalau AI yang kamu pakai tidak bisa melihat foto.

Angle iklan

Kreator dan format

Flow meniru gaya foto referensinya. Kalau referensinya foto studio, videonya cenderung ikut terlihat seperti iklan TV, bukan UGC. Karena itu ada prompt gambar untuk mengubah foto model jadi foto kreator bergaya HP.

Tapi kalau foto model kamu sudah memenuhi syarat, prompt gambar tidak perlu dipakai. Syaratnya: foto candid gaya HP, bajunya sudah sesuai, dan latarnya cocok dengan lokasi iklan. Cukup ganti nama filenya jadi creator.png lalu langsung pakai di Flow, dan centang kotak ini.

Prompt siap ditempel

Cara pakai

  1. Klik tombol Salin prompt.
  2. Pilih salah satu AI (ChatGPT, Gemini, atau Claude), lalu klik Buka.
  3. Di AI tersebut, mulai chat baru. Lampirkan semua foto produk. Kalau kamu sudah punya foto model, lampirkan juga supaya hasilnya lebih bagus.
  4. Tempel prompt yang tadi disalin, lalu kirim.
  5. Kalau ada yang kurang pas, minta perubahan di chat yang sama. Contoh: "Buat dialog shot 2 lebih santai."

Hasil yang akan kamu dapat dari AI

1. Prompt gambar kreator
Tempel ke ChatGPT Images atau Nano Banana bersama foto model.png. Simpan hasilnya sebagai creator.png.
2. Shot list
Naskah iklan per adegan: lokasi, aksi kreator, produk tampil atau tidak, dan dialognya. Ini untuk kamu baca dan cek dulu, bukan untuk ditempel ke Flow. Edit dialog di tahap ini gratis, sedangkan generate ulang video makan kredit.
3. Prompt Flow per shot
Satu prompt untuk satu klip video. Tempel satu per satu di Flow, dengan creator.png dan foto produk sebagai ingredient.
4. Briefing Agent mode
Satu teks untuk membuat semua shot sekaligus. Hanya jalan kalau Agent mode di Flow sudah aktif.
5. Skrip voiceover
Dialog lengkap dengan timing, untuk dibuat suaranya di ElevenLabs lalu digabung di CapCut.
