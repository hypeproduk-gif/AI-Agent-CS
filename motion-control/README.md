# Motion Control Prompt

Generator prompt gratis (tanpa API). Buka `index.html` langsung di browser.

1. Isi gerakan video, deskripsi model, produk, latar, rasio, gaya → **Buat Prompt**.
2. **Prompt Gambar** → Nano Banana/ChatGPT + lampirkan foto model & produk.
3. **Prompt Motion Control** → Kling Motion Control: gambar hasil + video referensi.
4. **Prompt Alternatif** → Google Flow/Veo kalau tanpa video referensi.
