# Video ke Prompt

Buka `index.html` di browser. Upload video referensi (+ foto model & produk opsional) → Gemini menganalisis video → keluar:
1. Analisis video (gerakan per detik, kamera, latar)
2. Prompt gambar (Nano Banana/ChatGPT)
3. Prompt Kling Motion Control
4. Prompt Google Flow/Veo

Butuh Gemini API key gratis: https://aistudio.google.com/apikey (disimpan di browser saja). Video disarankan < 20MB.
