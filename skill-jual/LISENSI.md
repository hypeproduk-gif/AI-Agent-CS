# Lisensi Penggunaan — UGC Flow Studio

Dengan membeli produk ini, kamu mendapat lisensi pribadi dengan ketentuan berikut:

**Boleh**

- Memasang skill di akun Claude milikmu sendiri.
- Memakai hasilnya (prompt, naskah, video) untuk kebutuhan komersial: iklan produk sendiri, affiliate, atau jasa untuk klien.

**Tidak boleh**

- Membagikan, menjual ulang, atau mengunggah file skill ini ke orang lain atau ke tempat umum.
- Mengklaim skill ini sebagai buatanmu sendiri.

Pelanggaran lisensi dapat membuat akses update dihentikan.
