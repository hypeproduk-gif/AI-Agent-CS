# Salep Glowing FILO — 23 Briefing Agent Flow (23 Angle)

Setiap blok di bawah adalah **satu briefing Agent mode** (3 shot × 8 detik, ±24 detik). Salin satu blok, tempel ke Agent mode Google Flow. Kalau Agent mode tidak aktif, tempel per shot sebagai prompt biasa.

**Sebelum mulai:**
- Unggah ke Flow: `creator.png` (kreator) dan `filo-salep.jpg` (foto produk). Kalau nama file kamu berbeda, ganti semua `filo-salep.jpg` di bawah ini.
- Sesuaikan klaim dengan klaim resmi produk. Briefing ini sengaja hanya memakai klaim aman ("kulit kelihatan lebih cerah dan glowing", "lembap"), tanpa klaim medis, memutihkan, atau angka hasil.
- Bagian promo/stok sengaja tidak disebut. Tambahkan sendiri hanya kalau memang ada promonya.
