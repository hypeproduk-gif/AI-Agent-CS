# Salep Glowing FILO — 23 Prompt Gambar (23 Angle)

Untuk ChatGPT Images atau Nano Banana. Setiap prompt menghasilkan satu foto iklan bergaya UGC: kreator + produk FILO.

**Cara pakai**
1. Buka chat baru, lampirkan **model.png** (wajah kreator) dan **filo-salep.jpg** (foto produk).
2. Tempel satu prompt, kirim.
3. Ganti rasio sesuai kebutuhan: **4:5** untuk feed, **9:16** untuk story/reels, **1:1** untuk marketplace.
4. Teks headline ditambahkan di Canva/CapCut supaya hurufnya rapi. Saran teks ada di bawah tiap prompt.
5. Gambar ini juga bisa dipakai sebagai `creator.png` atau frame awal untuk video Flow angle yang sama.

Kalau nama file kamu berbeda, ganti `model.png` dan `filo-salep.jpg` dengan Find & Replace.
